# 一言日記

夏休みの宿題「一言日記」をテーマにした、ローカルで動くウェブアプリです。

- 期間を3日〜31日で決めて日記を作る
- 1日1行ずつ書く（自動保存）
- 全部の日がうまると「完成フォルダ」に自動で入り、一覧表示・印刷ができる
- データはブラウザの localStorage に保存（サーバー・ネット接続不要）
- 「バックアップを保存／読み込む」でJSONの書き出し・取り込みができる

## 使い方

`index.html` をブラウザで開くだけです。

## 開発メモ

- 1ファイル構成（HTML / CSS / JS）。ビルド不要
- 同じブラウザ・同じ場所（file:// または同じURL）で開くとデータが共有されます
- GitHub Pagesで公開することも可能（データは各自のブラウザ内に保存）
